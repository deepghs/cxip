# CSIP 下一版 (暂称 v4) 优化方案设计

日期：2026-10-27 起草，2026-10-29 修订 (画风按连续变化处理；Pixiv 数据；原发日期校正)。状态：待用户审阅。依据的分析数据在 `/data/neko/cxip_v3/eval/gap/`，脚本见文末。

> **2026-11-01 更新 (P0 检查点)：v4 不再使用 Pixiv。** 用户提供的 `pixiv_ai_s1-webp-4Mpixel` (s1) 实际是 AI 生成图的语料库，文件名 id 与 `pixiv_index` 的作品无关，Pixiv 图片的画师标签与图片内容无关 (证据见 `docs/csip_v4_p0_baseline_zh.md` §6.1)。用户在 P0 检查点决定 v4 去掉 Pixiv：§0.6、§4.1 的 Pixiv 部分、B3 (B3-P1 / B3-P2) 和消融 A7 都已取消，下文在原处标 **[已取消]**，其余内容未改写。G2 改用 B1 + B2 + csip_eval_public，与 Kaloscope 的公平对比只看 B2。原发日期校正不受影响 (只用 `pixiv_index` 的作品元数据，不用 s1 图片)。

## 0. 背景

### 0.1 用途 (用户确认)

- 零样本画风检索：查询图多来自训练时没见过的画师。
- 画风聚类：无标注图集的画风发现。
- 生成模型数据集清洗和标注。用户以前按时期把同一画师拆成不同的画风标签。2026-10-29 确认：可以改用 **"画师 tag + 年份或阶段 tag" 的组合**，让生成模型自己学中间的连续过渡。

因此 CSIP 要学的是 **"同一时期的画法"**，不是 "同一画师的任意两张"。时间相近的作品应该最像，相隔越久越不像，变化速度因画师而异。"跨十几年认出同一画师" 是次要能力。

### 0.2 现状诊断 (v3 发布版 vs Kaloscope 3.0)

| 现象 | 数据 |
|-|-|
| v3 在公平集 (两边都没见过的 100 个画师) 上只领先 0.03 PR-AUC | v3 0.830 / Kaloscope 0.798；test100 上领先 0.10 |
| 差距主要来自跨多年的同画师对 | test100 年份差 0 年：v3 0.869 / K 0.857；≥6 年：0.575 / 0.301 |
| 公平集偏向短职业生涯和新图 | 83% 的同画师对在 2 年内 (test100 48%)；43% 的图是 2024-2025 年 |
| 去偏 (事后擦除) 每个集合固定损失约 0.02 | 公平集：未擦除 x4 0.855，发布版 0.830 |
| Kaloscope 有 v3 没有的同期画风信息 | v3+K 融合：公平集 0.868 (+0.038)，test100 0.880 (+0.015)；同源 v3+x4 融合 0.851 (不涨)；增益集中在 0-2 年对 (+0.04~0.05 召回)，≥6 年对下降 |
| v3 的数据旧、训练量小 | 数据截至 2024 (无 2025 图)；v3 约 7.2M 样本次，Kaloscope 约 94M (46k 步 × 2048)；v3 领先幅度随图片年份单调缩小 (≤2019 +0.062 → 2025 +0.020) |
| Kaloscope 跨来源阈值更稳 | 跨集最大 F1 损失 0.105，v3 0.272 |
| Kaloscope 内容偏置约为 v3 两倍 | I_content 0.170 / 0.087；同角色不同画师误报 1.69% / 0.85% |

### 0.3 画风随时间的变化 (`v3/scripts/style_drift.py` 与一次性试验)

保持度 r = (该时间差的同画师平均 cos - 跨画师平均 cos) / (近期 (<0.5 年) 同画师平均 cos - 跨画师平均 cos)。特征用 v3 x4 (未擦除) 与 Kaloscope 的融合。

- **变化是连续渐变的**。全体中位数：1-2 年 0.90，3-4 年 0.80，4-6 年 0.73，6-10 年 0.65，10 年以上 0.52。
- **单个画师也是渐变，不是台阶**。test100 中跨度 ≥4 年的 87 个画师，只用彩色图、同日取平均，投影到 "早期 → 晚期" 方向后拟合 S 形过渡：主要过渡走完 10%→90% 的时间中位数 7.1 年 (p25 3.9、p75 10.9)，占职业跨度的 66%；不到 1 年的 (近似突变) 只有 5%，1-3 年 15%，≥3 年 80%。
- **变化快慢因人而异，差约 4 倍**。3-4 年的保持度：p10 0.64、p50 0.80、p90 0.92；1-2 年：p10 0.84、p90 0.96。
- **快慢是画师的稳定属性**：两个模型测出的画师变化速度排名 Spearman 0.76。
- **画师内部的差异主要来自时间**：不看时间把画师的图分两类，有显著差异的 13% 画师中 92% 的两类在时间上分开；同时期并存两种画法的约 1%。
- **硬切时期不可靠**：用 "段内误差最小" 的切点算法时，粒度稍调细切点就变多，不同模型切点只部分一致 (ARI 0.45-0.67)。这符合 "在连续斜坡上找台阶" 的预期。粒度接触表 (`granularity_v1/`) 还显示成批上传的同日图和成批的漫画页会被切成假时期。
- **固定 365 天窗口很浪费**：test100 这类长职业画师只有 27% 的同画师对在一年内。
- **年代估计可以直接测**：同一画师内，用 5 个最像的其他图 (排除同一上传日) 的日期估计这张图的日期 (test100，跨度 ≥3 年的 93 个画师，21,710 张)。平均误差 v3 发布版 0.95 年、v3 x4 0.94 年、Kaloscope 0.89 年；只用画师日期中位数猜是 2.51 年。这是不依赖任何分期、只依赖日期的 "画师内时间分辨率" 指标 (§5.3)。

### 0.4 日期本身有误差 (Danbooru 上传时间 ≠ 原发时间)

Danbooru 的 created_at 是上传到 Danbooru 的时间。能查到原发时间的帖子 (Twitter status id 的时间戳 / Pixiv 作品时间)，用 Danbooru2026 单画师未删除帖子统计：

| 原发来源 | 帖子数 | 上传滞后中位数 | 滞后 >1 年 | p95 滞后 |
|-|-|-|-|-|
| Twitter (status id 解出时间) | 358 万 (33%) | 0 | 13.1% | 2.8 年 |
| Pixiv (pixiv_index 中的作品) | 194 万 (18%) | 0 | 15.1% | 4.4 年 |

滞后 >1 年的比例逐年上升 (2015 年上传 3.5%，2024 年 17%，2025 年 22%)，即近年常有人补传旧图。带 pixiv_id 的帖子占 53%；Pixiv 作品 id 随时间单调增长，没在索引里的也能按 id 插值估出日期。所以多数帖子能校正到原发时间。

## 1. 目标、非目标、反目标

### 目标

- G1 **同期画风**：在新 benchmark 的同期对 (时间差 <1 年及 1-3 年两层，见 §5) 上，PR-AUC 和 MAP@R 都显著高于 v3 发布版 (在 B1 上判) 和 Kaloscope (在 B2 / B3-P2 上判；B3-P2 **[已取消]**，只看 B2)。按画师配对 bootstrap，95% CI 不跨 0。
- G2 **阈值稳定**：用默认读出 (s·cos + b) 和单一全局阈值 (config.threshold) 时，跨来源最大 F1 损失不高于同一估计方法下 Kaloscope 的值。参考：csip_full_eval 的精确曲线给出 Kaloscope 0.105、v3 0.272；§0.7 的直方图估计给出 v3 0.223。两种估计方法不同，benchmark v2 统一用一种。按来源分别校准、CSLS 外部参照只作补充报告，不计入 G2。
- G3 **画风年代工具**：给数据集里每张图输出可直接用作 tag 的年份 (校正到原发时间)、画风估计年份、是否和日期矛盾，以及每个画师的变化速度 (§4.8)。验收 (B1 dev，用校正后的日期)：v4 的年代估计误差显著低于 v3 发布版，且不高于 Kaloscope；日期矛盾标记在注入的 "错误日期" 图上 AUROC ≥ 0.8 (§5.3 指标 5)。
- G4 **内容偏置不升**：I_content ≤ 0.09、I_char ≤ 0.035 (v3 发布版 0.087 / 0.031)，同角色不同画师误报不高于 v3 发布版，且不付事后擦除那 0.02 (或付得更少)。
- G5 **跨时期识别不严重退化**：≥6 年层的召回比 v3 发布版下降不超过 0.05 (次要能力，允许小幅让步)。

### 非目标

- 人工标注 (用户目前没有标注时间)：所有真值靠元数据 (画师、原发日期)、模型间一致性和独立弱信号。
- 把画师作品硬切成不重叠的时期 (用户已改用 "画师 + 年份 / 阶段" tag 组合)。
- 新骨干预训练、换骨干：沿用 AnimeDINOv3。
- CCIP 改动。
- student 蒸馏：留到下一阶段，接口 (768 维 + Matryoshka + 校准分数) 保持不变，以便沿用 v3 的蒸馏方案。

### 反目标 (技术上达标也算失败)

- 把 "画师同一性" 当画风：为了跨十几年匹配而硬拉不同时期。
- 靠内容认画师：因为画师常画同一部作品，就让 "画什么" 成为相似的理由。
- 循环论证：用模型自己的输出 (切出的时期、估出的速度) 来评测它自己。
- 只盯一个混合总分调参，在测试集上过拟合。

## 2. 约束

- 算力：H200 的 4-7 号卡 (共享，开工前看 `nvidia-smi` 并和用户确认)；不碰 0-3 号卡。所有 python 命令显式设 `CUDA_VISIBLE_DEVICES` (CPU 任务设为空)。预算约 3-3.5 天 4 卡 GPU 时间 (用户已确认)。
- 实测吞吐 (4×H200，2B 全量微调)：384 约 455 img/s，512 约 213 img/s，640 约 120 img/s。
- 磁盘：根分区 (含 /data) 只剩约 87G；新数据集、特征、checkpoint 放 /scratch (RAID0，剩约 7.9T)。不写大量小文件，数据按 tar shard 打包。
- 无人工标注。
- Kaloscope 只作评测基线和分析工具，不用于训练或蒸馏 (我的决定：许可和独立性两方面都更干净)。
- 许可沿用 AnimeDINOv3 的口径 (CC BY-NC 4.0 + DINOv3 License)。Pixiv 数据集为内部私有，只用于训练和评测，不再分发。
- 现有评测集 (test100_0918、csip_eval_public、csip_unseen_v1) 保留，便于和历史版本对比。
- 给用户看的接触表只放全年龄 / sensitive 分级 (Danbooru g/s；Pixiv x_restrict = 0)。

## 4. 方案细节

### 4.1 数据 v2

**Danbooru 部分 (`danbooru-artist-v2`)**
- 来源：nyanko Danbooru2026 快照 + 本地 `danbooru-full-4mpixel-v1` shard (按 id 取图，方法同 `build_csip_unseen.read_members`)。图统一缩到短边 ≤ 640 (与 v1 一致)，webp，按 tar shard 写到 /scratch。
- 规则：单画师、未删除、jpg/png/webp、无 ai-generated / ai-assisted；作品族 = parent_id 或自身 id，同族只留一张进同一划分。
- 元数据逐图保存：画师、日期 (见下)、作品族、上传日、角色 / 作品 / 画法标签、分级、原尺寸。
- 类：≥30 张的画师作训练类 (约 6.2 万)。是否把 10-29 张的画师加进来，作为消融 A6。
- 本地缺的约 1.86M 张 (≥30 张画师的 26%) 先不补；若 A6 显示更多数据仍有明显收益，再评估下载。
- 划分在建数据时一次定死 (按画师整体划分，见 §5.2)，写进 manifest；训练、调参、漂移估计都不得碰 test / sealed 画师。

**原发日期校正 (我的决定)**：每张图存 `date` 和 `date_source`。取以下可得时间中最早的一个：
1. Twitter status id 的时间戳；
2. Pixiv 作品时间 (pixiv_index 中有的直接用，没有的按作品 id 在索引上单调插值)；
3. Danbooru created_at (兜底，标记为 "上传时间")。

只有兜底日期的图仍然使用，但在评测的年代指标里单独报告。

**Pixiv 部分 (`pixiv-artist-v1`，同样按 tar shard 写到 /scratch，我的决定)** **[已取消]** (v4 不用 Pixiv；pixiv-artist-v1 已删除)
- 只取 Danbooru 上没有的作品 (按 Danbooru 的 pixiv_id 去重)，避免同一张图在两个来源各出现一次。
- 一个 Pixiv 作品的所有页是一个作品族；每个 epoch 每作品最多取 2 页 (页数多的作品常是差分或漫画)。
- 标签：能唯一对上 Danbooru 画师 (≥3 个共同作品) 的账号并入该画师的类，这样同一类里同时有两个来源的图，构成跨来源正样本；只在 Pixiv 的账号 (≥30 个作品) 作为新类。对不上或一对多的账号不用 (可能是社团或多人账号)。
- 日期用 Pixiv 的 created_at (原发时间)。
- 排除 illust_ai_type = 2；2022-10 前未标记的作品不额外处理 (见风险表)。
- B1 / B2 / B3 画师对应的 Pixiv 账号同样排除在训练外。
- 用不用由消融 A7 决定。

### 4.2 阶段 0：同期画风模型 (测量工具)

- 目的：v3 被训练成拉近不同时期，用它测漂移会低估变化；Kaloscope 见过大多数画师。需要一个只学 "同一时期" 的模型来测量各画师的变化速度。
- 配方：v3 的 2B 骨干与 head。正样本只取同画师、|Δt| ≤ 1 年 (用校正后的日期)、不同作品族；同画师超出 1 年的对忽略，不当正也不当负。其余同 v3 (crossed 同角色难负样本 25%、SigLIP 损失)。短预算 (约 2-3M 样本，384，约 2 小时)。
- 验收：在 benchmark v2 dev 的 <1 年层不低于 v3 发布版；它测出的变化速度排名与 Kaloscope 的 Spearman ≥ 0.7 (与本轮分析一致)。

### 4.3 漂移估计 (每画师变化速度)

输入：一个画师的图片向量 (阶段 0 模型) 和日期。输出：该画师的保持度曲线 r_a(Δt) 和一个概括数 (保持度降到 0.8 所需年数)。

- 预处理：同一天上传的图先合成一个时间点 (取均值)，避免成批上传的一套图主导估计；只用彩色插画 (黑白 / 漫画 / 草图 / 线稿的画法差异不是时间造成的)。以漫画为主、彩色图太少的画师，改为全用黑白图估计，并标记出来。
- 内容控制：算保持度时只用不共享角色 / 作品标签的图对，避免 "画师换了一部作品画" 被当成画风变快。
- 曲线：按时间差分桶，算同画师平均相似度，归一化成保持度 (定义同 §0.3)，拟合单调递减曲线 (等渗回归)。
- 收缩：向全体中位曲线做经验贝叶斯收缩，图少、跨度短的画师更依赖全体曲线；跨度之外 (没观测到的大时间差) 完全用全体曲线外推。
- 并存画法 (约 1% 画师)：不特殊处理，保持度曲线会自然偏低。
- 防循环：训练用阶段 0 模型估出的曲线；评测的主指标只依赖画师和日期 (§5)，不依赖任何模型估出的速度或时期。漂移估计最多迭代 2 轮 (阶段 0 → v4 第一轮 → 重估)；两轮速度排名 Spearman < 0.9 就停在第一轮。

### 4.4 训练目标：连续时间核

沿用 v3 的成对 sigmoid 损失 (score = s·cos + b)，把每对的目标从 0/1 改成随时间差连续变化：

| 对的类型 | 目标 |
|-|-|
| 同画师、不同作品族 | y = r_a(\|Δt\|)：时间差 0 时为 1，随时间差按该画师的速度连续下降 |
| 同画师、同作品族 | 忽略 (同 v3 / Kaloscope) |
| 不同画师 | 0；同角色 / 同作品的 crossed 组保留 |

- 用二元交叉熵 BCE(σ(s·cos+b), y)。y=0.5 的最优 logit 是 0，即这类对落在 "同期" 与 "陌生" 之间。检索时时间最近的作品排最前，同画师其他时期的作品随时间差依次往后，最后才是其他画师。
- 没有切点，也就没有 "切错" 的问题。变化快的画师相隔两年就明显降低目标，变化慢的画师相隔十年仍接近 1。
- 采样：P×K，K 张在该画师的时间轴上分散取 (一半在锚点 1 年内，一半更远)，保证每个 batch 同时有近、远两类对。crossed 组比例沿用 25%。
- 标签怎么来：先训阶段 0 模型 (§4.2，它的标签只用画师 + 日期)，用它给训练集所有图提特征，按 §4.3 给每个画师估出 r_a(Δt) 并存成查找表；v4 训练时每对同画师图按日期差查表得到 y。训练中不再调用阶段 0 模型。
- 先简后繁：A3g 全体共用一条曲线 (所有画师同一个 r(Δt)，只依赖全体中位曲线，几乎不受单个画师估计噪声影响)；A3a 每画师各自的曲线。A3a 没有显著好于 A3g，就用 A3g。
- 对照 (消融)：A1 固定 1 年窗口 (远对忽略)；A2 硬时期 (按 ρ*=0.8 切分，同期为 1、跨期忽略)；A3g / A3a 连续时间核 (主方案)。
- 备选 (消融 A4)：双头。画风头用连续时间核；身份头用全时期正样本。两个 768 维向量都导出 (默认用画风头)。只在 A3 的跨时期指标 (G5) 退化过多时启用。
- 假设：v3 的内容偏置有一部分来自跨时期正样本。画师早年和近年的作品画法不同时，能把它们拉近的共同线索往往只有 "画什么"。连续时间核会降低远距离对的拉力，可能自然降低内容偏置。A3 要测 I_content / I_char，验证或否定这一点。

### 4.5 去偏

- 训练期 tag 混淆擦除 λ = 0.01 保留 (v3 证明有效且代价小)。
- 事后线性擦除改为 "需要时才用"：v4 训完先测 I_content / I_char 和同角色误报；若已达到 G4，就不擦，省掉 0.02；否则再按 v3 的 kc/kh 网格擦，并记录代价。

### 4.6 规模与分辨率

- 训练量：从约 7.2M 样本次提高到约 20-30M (主段 384 + 末段 640，FixRes)。按实测吞吐，20M@384 约 12 小时，3M@640 约 7 小时，单次完整训练约 1 天 (4 卡)。
- 消融用短预算 (约 1M 样本 @384，约 40 分钟)，从 AnimeDINOv3 初始化 (不从 v3 teacher 初始化，避免带入跨时期偏差)。
- 扩量曲线：最佳配方在 1M / 3M / 10M 三个点、A0 在 1M / 3M 两个点上画 benchmark v2 dev 曲线，确认收益是否还在涨、新配方的优势是否随训练量保持，再定最终预算。
- 分辨率：640 末段沿用；测试时再比较短边 640 / 768 (v3 曾验证小图放大无用，大图未测)。

### 4.7 读出与校准

- 默认读出仍是 s·cos + b。
- CSLS (外部参照库 / 池内参照) 和 s-norm 作为可选读出，在 benchmark v2 的检索与阈值迁移任务上分别报告，按用途给推荐。
- 阈值：按来源分别给推荐阈值和 "阈值 → 精确率 / 召回率" 曲线 (沿用 v3 发布的 npy 曲线格式)。

### 4.8 交付：画风年代工具

面向 "画师 tag + 年份 / 阶段 tag" 的打标方式。

- **逐图输出** (json / parquet)：
  - `year`：校正后的原发年份 (§4.1)，可直接用作年份 tag；附 `date_source`。
  - `style_year`：画风估计年份。在同一画师的其他图 (排除同一上传日、同一作品族) 中找 k 个最像的，按相似度加权平均其日期。用途有三：没有日期的图 (其他来源的数据) 用它补年份；日期可疑时作参考；也可作为连续的 "阶段" 值。
  - `date_conflict`：`year` 与 `style_year` 相差超过该画师正常误差的图，例如补传的旧图、转载、错标画师，清洗时优先人工看。
  - 媒介标记 (彩色 / 黑白 / 漫画 / 草图)。
- **逐画师输出**：变化速度 (保持度降到 0.8 所需年数) 和保持度曲线。速度很慢的画师，年份 tag 基本不带信息，可以只用画师 tag；速度快的画师，年份 tag 最有用。
- **可选阶段 tag**：需要比年份更 "按人自适应" 的标签时，按容差 δ 把画师时间轴等量离散化。从最早的作品开始延伸，直到与起点的画风差超过 δ 就开新阶段 (`stage1`、`stage2`…)，变化快的画师阶段多、慢的少。δ 全局一个值，工具里可调。
- 每个画师可生成接触表 (按年份排列，标出 `date_conflict` 图)。
- Python API + CLI，可对整个数据集批量跑。

## 5. benchmark v2

### 5.1 原则

- 主指标的真值不依赖任何模型：只用画师 + 原发日期。
- 和用途一一对应：检索、聚类、清洗、年代标注各有任务化指标。
- 内容受控：跨内容正样本、同内容负样本单独报告。
- 池子构成固定：每画师张数、干扰图数量写死 (CSLS 试验表明构成会改变结论)。
- 统计：所有指标按画师做 1,000 次 bootstrap 给 95% CI；模型比较用配对 bootstrap；种子噪声单独测。
- 防过拟合：画师划成 dev / test / sealed。调参只看 dev；test 用于阶段性对比；sealed 每个发布版本只跑一次。
- 公平对比外部模型：外部模型训练集里有的画师单独列出；公平集的选择偏差 (短职业、新图) 用分层重加权到 Danbooru2026 全体画师的职业跨度 / 年份分布，报告 "总体加权" 分数。

### 5.2 测试集

| 集合 | 构成 | 用途 |
|-|-|-|
| B1 长职业留出集 | v3 训练时整体排除的 0918 测试画师 (798 人，test100 是其中 100 人；跨度 >8 年 468 人，≥100 张 675 人)，补上它们在 Danbooru2026 里的新图 (含 2025-2026)；每画师 ≤ 80 张，跨度内均匀取 | 主 benchmark：时间分层、年代估计；v4 与 v3 的对比 |
| B2 两边都没见过的画师 | 不在 Kaloscope 训练画师、不在 v3 / v4 训练集的画师 (csip_unseen_v1 的扩大版，按年份和职业跨度配额，含 2025-2026 才出现的画师) | 零样本泛化；与 Kaloscope 的公平对比 (分层重加权) |
| B3 非 Danbooru 来源 **[已取消]** | B3-P1：B1 画师在 Pixiv 上、Danbooru 没有的作品 (493 个画师，约 7 千个作品)，查询用 Pixiv 图、库用 Danbooru 图，画师相同、只换来源；B3-P2：只在 Pixiv 的账号中留出约 300 个 (≥30 个作品)，Kaloscope 与 v3 都没见过；csip_eval_public | 跨来源阈值迁移；B3-P2 也是与 Kaloscope 的第二个公平对比集 |
| 旧集合 | test100_0918、csip_eval_public、csip_unseen_v1 | 与 v1-v3 和 Kaloscope 的历史对比 |

- v4 训练集排除：B1 的 798 个画师、csip_eval_public 的画师、B2 的画师、B3-P2 的 Pixiv 账号，以及这些画师对应的 Pixiv 账号 (与 v3 的排除口径一致，并扩到 B2 / B3)。
- B1 按画师划成 dev / test / sealed (约 300 / 250 / 250，按职业跨度分层)；test100_0918 的 100 人全部放进 test，保持与旧结果可比。B2、B3-P2 同样划 dev / test / sealed。
- 对比口径：v4 vs v3 在 B1 上判 (两者都没见过这些画师)；v4 vs Kaloscope 在 B2 / B3-P2 (B3-P2 **[已取消]**) 上判 (三者都没见过)，并报告重加权后的分数；Kaloscope 在 B1 上的分数照列，但注明 "训练中见过"。

### 5.3 指标

1. **时间分层验证** (B1 / B2)：同画师对按原发日期差 Δt 分 <1 年、1-3、3-6、≥6 年四层，每层分别报告 PR-AUC 与固定 FPR 下的召回。**主指标 = <1 年与 1-3 年两层**；≥6 年层作为 "跨时期识别" 次要指标 (对应 G5)。负样本相同。另报告同画师内 "相似度随 Δt 单调下降" 的程度 (画师内相似度与 Δt 的 Spearman，取中位数)。
2. **年代估计** (B1 / B2 / B3-P1 (**[已取消]**))：方法同 §4.8 的 `style_year` (k=5，排除同一上传日和同一作品族)，报告平均绝对误差 (年) 和 1 年内命中率，对照 "画师日期中位数"。另报告内容受控版：近邻排除与该图共享角色或作品标签的图，防止 "画同一部作品" 帮忙估年份。只用原发日期可靠的图 (`date_source` 不是兜底的) 作真值。本轮 test100 参考值：v3 发布版 0.95 年，Kaloscope 0.89 年，对照 2.51 年。
3. **内容受控** (B1)：跨内容正样本 (两张图角色、作品标签都不重叠) 的召回；同角色 / 同作品不同画师负样本的误报率 (固定阈值)。
4. **检索** (零样本)：每个查询的库 = 同画师 <1 年的图 + 大量干扰图 (其他画师)，报告 MAP@R、R@1，以及把所有查询合在一起算的 µAP (等于强制全局阈值)。另按 "同画师任意时期都算对" 报告一次 (对应 "认画师" 用途)。
5. **清洗** (离群检测)：每个画师文件夹注入 5% 的外来图，四类分别报告 AUROC：(a) 其他画师中画风最近的图 (用不参与评测的模型挖)；(b) 同角色不同画师；(c) 同画师相隔 ≥ 6 年的图 (反映时期纯度)；(d) 日期被改错 ≥ 4 年的同画师图，用 `date_conflict` 打分 (对应 G3)。(a)-(c) 打分 = 到其余图的 kNN 平均相似度。
6. **聚类**：混合池 (若干画师 + 干扰图)，UMAP + HDBSCAN 与直接 HDBSCAN 两种，报告 BCubed F 和 ARI。
7. **阈值迁移**：在每个来源上定 best-F1 阈值，迁移到其他来源，报告 F1 损失和实际 FPR 与目标 FPR 之差；同时报告用默认阈值 (config.threshold) 时的 F1。B3-P1 单独报告 (只换来源，不换画师) **[已取消]**。
8. **偏置**：I_content、I_char (沿用 v3 的探针)。

## 7. 风险

| 风险 | 对策 |
|-|-|
| 漂移速度估计有噪声 (图少、跨度短的画师) | 经验贝叶斯向全体曲线收缩；主指标不依赖估出的速度；A3 vs A1 / A2 的对比直接检验连续核是否有用 |

## 8. 已定事项与留给实施者的决定

我的决定 (用户审阅时请重点核对)：
- 目标定义为 "同期画风"，跨时期识别降为次要并设退化上限 (G5)。
- 画风按连续变化处理：训练用连续时间核，不切时期；硬时期只作为消融对照 (A2)。软标签 = 阶段 0 模型估出的保持度曲线查表；先比全体一条曲线 (A3g) 和每画师曲线 (A3a)，后者不显著更好就用前者。
- 打标工具以年份 tag 为主 (校正到原发时间)，CSIP 提供画风估计年份、日期矛盾标记和每画师速度；阶段 tag 作为可选输出。
- 原发日期校正：Twitter id 时间戳 / Pixiv 作品时间优先，Danbooru 上传时间兜底。
- Kaloscope 不参与训练或蒸馏。
- 数据换 Danbooru2026，本地缺图先不补。
- **[已取消]** Pixiv 数据：只取 Danbooru 上没有的作品；账号唯一对上 Danbooru 画师才并类，纯 Pixiv 账号 ≥30 个作品才作新类；每作品每 epoch 最多 2 页；是否用由 A7 决定。B3 用 Pixiv 建同画师跨来源集 (B3-P1) 和新画师集 (B3-P2)。
- 事后擦除改为需要时才用。
- B1 用 v3 训练时排除的 798 个 0918 测试画师 (v4 也排除)；v4 vs v3 在 B1 上判，v4 vs Kaloscope 在 B2 / B3-P2 上判 (Kaloscope 见过 B1 画师；B3-P2 **[已取消]**，只看 B2)。
- G2 只看默认读出 + 单一全局阈值，目标是 "不高于同一估计方法下的 Kaloscope"，不是固定数值。
- G3 改为年代工具：年代估计误差低于 v3 发布版且不高于 Kaloscope，日期矛盾检测 AUROC ≥ 0.8。
- 漂移估计只用彩色图、同日合并。
- 种子：只有 A0 vs 最佳配方跑两个种子；差异小于种子噪声不下结论。
- P0 结束后设检查点，基线和 benchmark 构成经用户确认再训练。
- 算力约 3-3.5 天，紧时先砍 A4 / A6 / 第二轮重估。

留给实施者：
- 连续核的具体函数形式 (等渗曲线直接用，还是参数化成指数衰减、加温度)，以及采样中近 / 远对的比例。
- 漂移曲线的分桶和收缩强度。
- `style_year` 的 k 和权重、`date_conflict` 的阈值 (按 dev 上的误差分布定)。
- 阶段 tag 的默认 δ。
- benchmark 各集合的具体画师数和每画师张数 (在 §5.2 的量级内)。
- 消融的具体超参 (学习率、K、crossed 比例等沿用 v3，除非消融需要)。

## 9. 用户确认记录 (2026-10-29)

1. 没有现成的按时期拆好的标签。看了粒度接触表后指出：画风是逐渐连续变化的，硬切时期有问题。数据也证实了这一点 (§0.3)，所以方案改为连续处理。
2. 打标方式：可以接受 "画师 tag + 年份或阶段 tag" 的组合，让生成模型学连续过渡。
3. 算力预算约 3-3.5 天 4×H200：可行。
4. 非 Danbooru 数据：`deepghs/pixiv_ai_s1-webp-4Mpixel` (分析见 §0.6，用法见 §4.1 / §5.2)。**[已取消]** 2026-11-01 P0 检查点：s1 是 AI 图语料库，v4 不用 Pixiv。

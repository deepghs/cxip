# 优美现代风格雷达图生成器

这个脚本用于根据CCIP Zero Metrics数据生成优美现代风格的雷达图。

## ✨ 优美现代风格特点

- **优美渐变配色**: 采用现代前端设计审美的配色方案
- **清晰的视觉层次**: 
  - 实线 = OLD模型，虚线 = NEW模型
  - 圆形 = OLD模型，菱形 = NEW模型  
  - 温柔玫瑰粉(A=1)，清新薄荷绿(A=3)，优雅天蓝色(A=5)
- **完美的网格系统**: 
  - ✅ **清晰的同心圆网格线**: 完美的圆形网格提供精确参考
  - ✅ **优美的百分比标签**: 白色圆角标签盒确保最佳可读性
  - ✅ **径向网格线**: 从中心辐射的参考线
  - ✅ **微妙阴影效果**: 增加视觉深度
- **智能绘制优化**:
  - 🎯 **按面积排序绘制**: 自动计算各图形面积，按从大到小顺序绘制
  - 🔄 **防遮挡设计**: 确保小面积图形始终显示在上层，不被大面积图形遮挡
  - 📊 **智能分层**: 动态调整zorder值，实现完美的图层管理
  - 🔄 **固定图例顺序**: 图例保持逻辑顺序(A=1→3→5, OLD→NEW)，不受绘制顺序影响
- **标签优化**:
  - 📝 **防遮挡标签**: 指标标签外移至合适位置，带白色背景框
  - 🎯 **精确定位**: 标签位置经过精心调整，确保在所有情况下都清晰可见
- **服务器友好**: 无需GUI环境，直接保存超高质量PNG图片
- **同图全面对比**: 同一个N值的所有A值和模型类型都在一个雷达图中

## 使用方法

```bash
# 激活conda环境
conda activate anime_dino

# 运行脚本
cd /data/cxip
python plot_radar_charts.py
```

## 输出文件

脚本会在 `beautiful_radar_charts/` 目录下生成以下文件：

- `beautiful_radar_N20.png` - N=20的优美现代风格雷达图
- `beautiful_radar_N40.png` - N=40的优美现代风格雷达图  
- `beautiful_radar_N100.png` - N=100的优美现代风格雷达图
- `performance_summary.png` - 优美现代风格性能汇总表

## 数据格式

脚本期望CSV文件包含以下列：
- `model_type`: 模型类型 (old/new)
- `N`: N值 
- `A`: A值
- `top1_accuracy`: Top1准确率
- `top5_accuracy`: Top5准确率
- `precision`: 精确率
- `recall`: 召回率
- `f1`: F1分数

## 图表解读

雷达图显示了五个性能指标（Top-1/Top-5准确率、精确率、召回率、F1分数）的表现。图表越接近外圈表示性能越好。通过优美的现代风格设计，可以轻松识别：

1. **模型对比**: NEW模型（虚线+菱形）普遍优于OLD模型（实线+圆形）
2. **参数效应**: A值越大，模型性能通常越好（蓝色>绿色>粉色）
3. **规模影响**: 不同N值下的模型表现差异清晰可见
4. **精确读数**: 网格线和百分比标签支持精确的数值读取
5. **智能显示**: 自动按面积排序绘制，确保所有图形都清晰可见，无遮挡现象

### 绘制优化说明

脚本会自动分析每个模型组合的性能面积，并按以下顺序绘制：
- **第一层**: 面积最大的图形（通常是NEW模型的高A值）
- **最后层**: 面积最小的图形（通常是OLD模型的低A值）

这确保了性能较低的模型也能清晰可见，不会被性能更高的模型完全遮挡。
